## 🔑 Secure Password Generator

**Technologies:**  
`Python` `Secrets` `String` `Password Security`

👉 [View Project](https://github.com/brounverma-tech/secure-password-generator)

## 🛡️ File Integrity Checker

A Python cybersecurity tool that uses SHA-256 hashing to detect file modifications by comparing the current file hash with a previously saved baseline.

**Technologies:**  
`Python` `SHA-256` `Hashlib` `JSON` `File Handling`

👉 [View Project](https://github.com/brounverma-tech/file-integrity-checker)

---

## 🌐 Network Port Scanner

A Python TCP port scanner created to understand computer networking and cybersecurity fundamentals.

It scans selected ports and identifies ports accepting TCP connections.

**Technologies:**  
`Python` `Socket Programming` `TCP/IP` `Networking`

👉 [View Project](https://github.com/brounverma-tech/network-port-scanner)

---

## 🔍 Security Log File Analyzer

A Python cybersecurity project that analyzes log files, detects failed login attempts, counts activity by IP address, and identifies repeated failed logins.

**Technologies:**  
`Python` `File Handling` `Dictionaries` `Log Analysis` `Security Monitoring`

👉 [View Project](https://github.com/brounverma-tech/log-file-analyzer)
