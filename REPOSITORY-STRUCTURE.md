## Naming Rule for Future Repositories

Use clear category-based names whenever possible:

- Books: `book-<subject-name>`
- CRM: `crm-<module-or-project-name>`
- Cybersecurity: `cybersecurity-<tool-name>`
- C Projects: `c-<project-name>`
- Python Projects: `python-<project-name>`
- Websites: `web-<project-name>`

This keeps the repository list easy to scan even though GitHub does not support folders around separate repositories.
